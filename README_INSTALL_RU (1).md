# Opportunity Navigator 3.3 — каталог без большого JSON

В этой версии `universities_catalog.json` (около 2,1 МБ) **не нужен**. Приложение загружает данные из `catalog_manifest.json` (около 46 КБ) и 19 файлов в папке `country_databases/`.

## Как загрузить в GitHub через сайт

1. Скачайте ZIP-архив и **распакуйте его** у себя на компьютере. GitHub/Streamlit не извлекают файлы из загруженного ZIP автоматически.
2. Откройте репозиторий GitHub, где уже расположен `app.py`.
3. Создайте (если нужно) папку `country_databases` и откройте её. Если GitHub не даёт создать пустую папку, можно в веб-интерфейсе выбрать «Add file → Create new file», написать `country_databases/.gitkeep`, сохранить, а затем открыть папку.
4. Находясь **внутри** `country_databases`, выберите `Add file → Upload files`. Выберите все 19 файлов `*.json` из распакованной папки и нажмите `Commit changes`.
5. Вернитесь в папку репозитория с `app.py`. Через `Add file → Upload files` замените `app.py` и загрузите `catalog_manifest.json`. Если нужных служебных файлов ещё нет, добавьте `catalog_i18n.py`, `program_search.py`, `learning_tools.py`, `psychological_support.py` и `learning_content.json` из того же архива.
6. Проверьте, что `catalog_manifest.json` расположен **рядом с** `app.py`, а 19 стран — в подпапке `country_databases` рядом с ними.
7. После успешного запуска можно удалить **старый** `universities_catalog.json` из репозитория: версия 3.3 его не использует. Не удаляйте его до того, как проверите работу новой версии.
8. Дождитесь перезапуска Streamlit; если необходимо, нажмите Reboot app на панели Streamlit Cloud.

## Что делать, если GitHub не принимает файл

- **Не копируйте JSON целиком в редактор GitHub** — используйте пункт `Upload files`.
- Загружайте JSON стран изнутри папки `country_databases`. Можно отправить их двумя партиями, если браузер не справляется со всеми сразу.
- Не загружайте ZIP напрямую вместо распакованных файлов.
- Если загрузка одного из JSON не удаётся, пришлите сообщение об ошибке или скриншот: ограничение может быть связано не с размером, а с интерфейсом или правами на репозиторий.

## Как проверить

- Откройте раздел университетов: должны загружаться 19 стран и 184 университета.
- Выберите ОАЭ и направление «Данные и искусственный интеллект»: должен появиться MBZUAI.
- Измените язык интерфейса на арабский: названия стран и направлений должны перевестись, поиск сохраняется.

Дополнительно в среде Python (если доступна):

```bash
python validate_country_catalog.py

python test_localization_v32.py
```

Служебные тесты и проверки проведены: 19 стран, 184 университета, 1 565 записей программ, 46/46 общих направлений поиска; все объекты из прежнего общего каталога воспроизводятся (без потери записей, профилей и источников). Проверка запущенного браузера на вашем конкретном Streamlit-сервере ещё необходима.
