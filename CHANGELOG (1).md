# Opportunity Navigator — v0.6 changelog

## Tutor
- Added explicit subject and topic selection.
- Added repeated follow-up questions inside one tutoring session.
- Improved follow-up logic for linear equations, graphs/functions, English articles, loops and admissions questions.
- Kept simpler explanation, hint, example and check-your-understanding controls.

## Learning Hub
- Replaced a fixed small lesson length with adaptive practice.
- Starts with three core questions.
- Adds extra remedial questions when mistakes occur.
- More mistakes trigger more extra practice.
- Wrong answers always show the explanation before retry.
- Lesson state and completion are persisted in the demo progress token.
- Expanded remedial question banks for English, coding, study skills and university applications.

## Profile and persistence
- Current page can be restored after refresh.
- Requirement checklist and exam tracker now persist.
- Saved opportunities, lesson progress, support counter and admissions target continue to persist.
- Free-text support/community/essay content is intentionally excluded from URL persistence.

## Community safety
- Phone-number, email and social-handle blocking remains active before moderation submission.

## Opportunities
- Official provider links remain direct link buttons.
- Saved opportunities continue to update pathway counters.

## University Planner
- Added public-web search for candidate official pages by target country/university/program.
- Added separate research queries for course requirements, exams/language scores, scholarships and application writing.
- Kept official-page extraction with verification warnings.
- Added persistent exam/score tracker with source URL.
- Expanded motivation-letter builder with reflection and a draft-strength checklist.
- Reframed portfolio guidance around depth, personal contribution, results and proof rather than a universal achievement count.

## Documentation
- Updated the in-app About page, README and prototype limitations to reflect v0.6 accurately.
