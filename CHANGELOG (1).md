# Changelog — v1.4

## University research
- Rebuilt the generic University Planner around AI-first official-source research.
- Added strict structured-output schema for admissions research.
- Added a targeted second web-search pass when exam or English-test data is missing.
- Added admission-pathway classification so regular undergraduate, transfer, mid-year, foundation and direct-admission requirements are not mixed.
- Added official-domain validation for every returned requirement/source.
- Added sitemap discovery for deeply nested admissions pages and official PDFs.
- Added table-aware HTML extraction.
- Expanded targeted official-domain searches for IELTS/TOEFL/SAT/ACT and admission-policy PDFs.
- Preserved section-level English scores such as IELTS Writing/Reading/Listening/Speaking.
- Strengthened numeric validation to reject years, IDs and impossible exam scores.

## UI
- Deep research now shows the admission route used.
- English-language tests and entrance exams have dedicated structured sections.
- Removed more raw navigation/boilerplate text from fallback results.
- Generic section titles now localize correctly instead of remaining in English.
