# Changelog — v1.3

## Fixed
- Fixed blank/invisible selected-language value in the dark sidebar.
- Added a more reliable direct translation fallback.
- Added built-in Kazakh translations for core navigation/Home as an offline-safe fallback.
- Fixed false university-domain discovery such as government/presidential sites being treated as a university.
- Fixed false SAT extraction from URLs, article numbers and legal-page identifiers.

- Removed grey raw extraction text from exam cards.
- Removed learner-facing technical API captions.

- University Planner now searches more targeted official-domain queries for programmes, exams, English requirements, deadlines, documents and scholarships.
- Irrelevant news/legal pages are filtered before admissions extraction.
