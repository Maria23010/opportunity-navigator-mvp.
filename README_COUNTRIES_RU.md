# Opportunity Navigator 2027 — версия 3 (расширенная база вузов)

**Дата обновления:** 13 октября 2026. Данные используются для предварительного подбора бакалавриата, а не для автоматического решения о допуске или гарантии стипендии.

## Что изменилось

- **19 стран и территорий**, включая впервые добавленные **Объединённые Арабские Эмираты (ОАЭ)** и восстановленный Казахстан. Для каждой страны отдельный `JSON`.
- **183 университета**, **1 партнёрский провайдер** бакалаврских программ и **4 государственных маршрута/стипендиальные программы**.
- **1563 записи программ/направлений** в объединённом каталоге. Это *не* 1563 полностью проверенных открытых набора 2027 года.
- Все **46 пунктов меню «Направление бакалавриата»** имеют хотя бы один точный университетский результат **в общей базе**. При выборе конкретной страны часть направлений может отсутствовать. Приложение покажет сообщение и предложит посмотреть подтверждённые варианты в других странах, не подменяя направление.
- Вузовые карточки содержат **отдельные экзамены и минимумы**, где они опубликованы. Улучшены конкретные профили экзаменов для СПбГУ (МКН 2026), ВШЭ, ИТМО и некоторых других вузов, Astana IT University, КБТУ, Гнесинки, МГПУ, а также вузов ОАЭ. Пороги, не подтверждённые в доступных источниках, оставлены пустыми: **числа не придуманы**.
- В карточке выбранной страны отображается число точных результатов, рядом с документом — предупреждения о проверке программы и года; в выпадающем меню программ по умолчанию показываются **только соответствующие запросу**. Другие программы можно раскрыть переключателем.

## Какие файлы обновить в GitHub / Streamlit

В архиве откройте папку `application/`. В вашем GitHub замените файлы там, где уже лежит ваш `app.py`. Не загружайте внутрь дополнительной папки `application`, если в GitHub приложение сейчас размещено в корне.

```text
папка вашего Streamlit-приложения/
  app.py                            ← заменить
  universities_catalog.json        ← заменить (объединённая база)
  program_search.py                ← можно заменить из архива
  validate_country_catalog.py     ← можно заменить для проверок
  smoke_catalog.py                ← необязательный локальный тест
  learning_tools.py               ← оставить как есть
  learning_content.json           ← оставить как есть
  psychological_support.py        ← оставить как есть
  country_databases/               ← создать рядом с app.py или заменить папку полностью
    AE.json                         ← ОАЭ
    AU.json                         ← Австралия
    AZ.json                         ← Азербайджан
    BN.json                         ← Бруней
    CA.json                         ← Канада
    CN.json                         ← Китай
    GB.json                         ← Великобритания
    HK.json                         ← Гонконг
    HU.json                         ← Венгрия
    IT.json                         ← Италия
    JP.json                         ← Япония
    KR.json                         ← Южная Корея
    KZ.json                         ← Казахстан
    QA.json                         ← Катар
    RO.json                         ← Румыния
    RU.json                         ← Россия
    SG.json                         ← Сингапур
    TR.json                         ← Турция
    US.json                         ← США
  coverage_46_fields_by_country_2027.csv    ← необязательный отчёт
  coverage_summary_2027.json               ← необязательный отчёт
```

**Очень важно:** загрузчик объединяет основной каталог со страновыми файлами. Если два файла содержат один и тот же `entry.id`, первенство у данных в `country_databases/XX.json`. Поэтому обновляйте **объединённый JSON и соответствующие файлы стран вместе**. Если папку стран не загружать, объединённая база работает самостоятельно — однако обновления отдельной страны невозможны.

После загрузки в GitHub нажмите **Commit changes**, дождитесь перезапуска Streamlit и обновите страницу. Ваши секреты `.streamlit/secrets.toml`, другие модули, `requirements.txt` и Supabase/SQL не нужно удалять или заменять. Настройки развёртывания по-прежнему должны указывать на существующий `app.py`.

## Какие вступительные пороги показываются и почему иногда стоит «Не указан»

1. **Минимальный балл экзамена** (например, ЕГЭ по математике / TOEFL / IELTS) — нижний порог в конкретном маршруте, **не** фактический конкурсный балл на грант или бюджет.
2. **Конкурсный порог для участия в гранте** (например, ЕНТ для AITU/КБТУ) — не гарантирует получение гранта.
3. **Государственный порог ЕНТ**, указанный для Казахстана — общий нижний минимум в конкретном типе университета; не является подтверждением допуска на *каждую* программу. Для медицины, права, педагогики и отдельных университетов порог может быть выше.
4. **IELTS/TOEFL** — один из допустимых вариантов подтверждения языка, если вуз пишет «ИЛИ». TOEFL iBT 0–120 и новая шкала 1–6 — разные шкалы; старые опубликованные баллы не превращаются автоматически в требования новой шкалы.
5. **Неподтверждённая цифра** остаётся «Не указан / см. условия». Для многих направлений и стран на набор 2027 ещё нет надёжного опубликованного численного минимума. Нельзя ставить случайные или средние числа.

Поступление российских граждан по ЕГЭ, прямое иностранное зачисление, бюджет по соглашениям и стипендиальные конкурсы отличаются. Порог, справедливый для одного маршрута, не следует переносить на другой. Для творческих программ иногда нужны портфолио, собеседование, прослушивание или внутренний экзамен, а не один ЕГЭ. Для программ медицины и стоматологии возможны ограничения по типу/стране школьного аттестата.

## ОАЭ

Добавлены 6 университетов: United Arab Emirates University, American University of Sharjah, Khalifa University, New York University Abu Dhabi, University of Sharjah и Abu Dhabi University. Данные основаны на опубликованных вузами каталогах; включены профильные требования, где их удалось подтвердить. Например, у некоторых университетов есть минимумы IELTS/TOEFL для международного маршрута и отдельные условия по школьным предметам или типу аттестата. Это не единое правило для всей страны.

В ОАЭ сейчас **44 из 46** направлений меню имеют хотя бы одну реальную запись. Исключения — «Автомобилестроение» и «Материаловедение»: самостоятельные подходящие степени из выбранных официальных каталогов на этот момент не подтверждены. Вместо выдуманных результатов пользователь увидит предложение посмотреть другие страны.

## Сводная проверка всех стран

Файл `application/coverage_46_fields_by_country_2027.csv` содержит **19 × 46 = 874 строки**. В нём по каждой паре «страна × направление» указано число вузов **с точным совпадением** и примеры. Поиск в общей базе закрывает все 46 категорий, **но не каждую из 46 категорий в каждой из 19 стран**. Отдельно подсчитаны строки, где хоть для одной совпавшей программы доступен числовой показатель, однако он может относиться к общему экзамену/языку, а не к индивидуальному факультету.

## Локальная проверка (Python 3.10+)

В папке с `app.py` выполните:

```bash
python validate_country_catalog.py
python smoke_catalog.py
python -m py_compile app.py program_search.py
```

`validate_country_catalog.py` проверяет 19 файлов, ID, связность профилей и источников. `smoke_catalog.py` использует настоящий загрузчик и поиск из `app.py` через выделение чистых функций и проверяет 46 направлений без необходимости ставить Streamlit. Все эти проверки пройдены. **Полноценное открытие интерфейса на вашем Streamlit-домене, заявка абитуриента и проверка всех 1563 программ на 2027 год не выполнялись**.

### Как поддерживать актуальность

В любой JSON-карточке новые требования должны иметь собственную ссылку (`source_ids`), дату/цикл поступления, тип экзамена и шкалу, а для программ — уточнение требований по гражданству. Менять `record_status` предварительной записи на проверенную можно только после сверки с официальным каталогом. Часть оригинальных записей из предыдущей версии по-прежнему помечена `discovery_only` — это **подсказки для изучения**, а не подтверждённый открытый набор.
